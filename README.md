# Matemática Divertida

Site educativo feito em HTML, CSS e JavaScript puro para crianças praticarem:

- Soma
- Subtração
- Multiplicação
- Divisão
- Modo misturado

## Como usar

1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Não é necessário instalar nada nem usar servidor.

## Recursos

- 3 níveis de dificuldade
- 10 questões por rodada
- Pontuação por estrelas
- Contador de acertos
- Sequência de acertos
- Dicas específicas por operação
- Feedback imediato
- Confetes ao acertar
- Layout responsivo
